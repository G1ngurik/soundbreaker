# Sound Breaker — мод для Minecraft

Реализация механики из видео «Я не могу ЛОМАТЬ блоки, пока не повторю их ЗВУК».

Блок не ломается обычным кликом: открывается окно проверки, где игрок записывает
голос в микрофон и пытается повторить звук разрушения блока. Мод сравнивает форму
волны и ломает блок только при схожести не ниже порога.

## Что умеет

- Перехват ломания (клиентский mixin `ClientPlayerInteractionManager#attackBlock`).
- Реальный звук конкретного блока из `BlockSoundGroup` + декодирование `.ogg` через JOrbis.
- Две осциллограммы, **живая** волна во время записи, шкала схеможести с отметкой порога.
- Кнопки: оригинал, запись/стоп, своя запись, «Готово». Горячие клавиши: **R** — запись,
  **Пробел** — оригинал, **Enter** — готово.
- Счётчик попыток и лучший результат, иконка блока в окне.
- После успеха: звук-подтверждение, частицы разрушения, сообщение в чат.
- Надёжное разрушение в выживании: подавляется `ABORT_DESTROY_BLOCK`, который ваниль
  отправляет сразу после закрытия GUI.
- После успеха тип блока «разблокируется» на настраиваемое время — окно не выскакивает
  снова при каждом блоке того же типа.

## Сборка

Нужен JDK 21:

```bat
gradlew.bat build
```

Готовый мод: `build/libs/soundbreaker-1.0.1.jar`.

## Установка

1. Fabric Loader для Minecraft **1.21.1**.
2. fabric-api (`0.116.18+1.21.1` или совместимый).
3. Положить `soundbreaker-1.0.1.jar` в `mods`.
4. Разрешить доступ к микрофону Java/Minecraft в Windows.

## Настройки (`config/soundbreaker.properties`)

```properties
# минимальная схожесть в процентах
similarity_threshold=50
# длительность записи, секунды (0.3 - 5.0)
record_seconds=1.5
# включить механику
enabled=true
# не показывать окно повторно для уже пройденного типа блока
remember_success=true
# сколько секунд действует такой «пропуск» (0 = всегда спрашивать)
pass_seconds=20
# эффекты: звук, частицы, сообщение в чат
effects=true
```

Если хочешь, чтобы окно появлялось **каждый раз** без исключений — поставь
`remember_success=false` (или `pass_seconds=0`).
